# الهوية البصرية (الوضع الفاتح - Light Mode)

هذا المستند يحدد القواعد الخاصة بالوضع الفاتح (Light Mode) بناءً على الهوية البصرية الأساسية لمشروع "ويكند جو" (Weekend Go)، مع الحفاظ على الأناقة والرقي (Premium Tech).

## 1. الفلسفة التصميمية
يظل تأثير الزجاج الضبابي (Glassmorphism) هو التأثير المهيمن، ولكن مع خلفيات مضيئة وشفافة بدلاً من المظلمة. يعطي التصميم إحساساً بالنقاء والانتعاش النهاري، مشابهاً لتجربة السفر في الصباح الباكر.

## 2. لوحة الألوان المعتمدة للوضع الفاتح (Light Mode Colors)

| اسم اللون | الاستخدام | الكود التقريبي (Hex) |
| --- | --- | --- |
| **Pure White** | الخلفية الأساسية للموقع | `#FFFFFF` إلى `#F8FAFC` |
| **Soft Glass** | البطاقات والقوائم (خلفية شفافة) | `rgba(255, 255, 255, 0.75)` |
| **Deep Space Blue** | النصوص الأساسية والعناوين | `#0B1325` |
| **Electric Cyan** | العناصر النشطة والتوهج | `#00E5FF` (مع تعميق طفيف لزيادة التباين إن لزم) |
| **Neon Lime** | أزرار الدعوة لاتخاذ إجراء (CTA) | `#39FF14` أو الأخضر الفاتح `#A6CE39` |
| **Muted Silver** | النصوص الثانوية والمساعدة | `#8D99AE` أو أغمق قليلاً `#64748B` |

## 3. خصائص البطاقات الزجاجية
* **الخلفية:** شفافة بيضاء `rgba(255, 255, 255, 0.75)`
* **التغبيش الخلفي:** `backdrop-filter: blur(16px);`
* **الحدود (Borders):** خط رفيع جداً ناعم باللون الرمادي الشفاف `border: 1px solid rgba(0, 0, 0, 0.05);`
* **الظلال (Shadows):** ظلال ناعمة جداً للإيحاء بالارتفاع `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.05);`

## 4. التيبوغرافيا
* نفس عائلة الخطوط الأساسية (مثل Cairo / Tajawal).
* التباين: تُستخدم ألوان داكنة (مثل الكحلي `#0B1325`) بدلاً من الأبيض للقراءة الواضحة.

## 5. زر التبديل (Theme Toggle)
* يجب إضافة زر في شريط التصفح العلوي يتيح التبديل الفوري بين الوضعين (Dark / Light).
* يستخدم أيقونة "الشمس" للوضع الفاتح وأيقونة "القمر" للوضع الداكن.
